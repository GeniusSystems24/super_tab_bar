# super_tab_bar example

Demonstrates browser-style workspace tabs, per-tab page builders, pinned and
dirty states, overflow, hover previews, RTL, callbacks, and compact mobile mode.

The app uses `super_core 3.0.0` through `SuperMaterialThemeData.light` and
`SuperMaterialThemeData.dark`; `SuperTabBarThemeData` is derived automatically.

```bash
flutter pub get
flutter run
```
