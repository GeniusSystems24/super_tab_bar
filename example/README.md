# super_tab_bar example

Demonstrates browser-style workspace tabs, per-tab page builders, pinned and
dirty states, overflow, hover previews, RTL, callbacks, and compact mobile mode.

The app uses `super_core 3.3.0` through `SuperMaterialThemeData.light` and
`SuperMaterialThemeData.dark`, with the required `SuperTextTheme` supplied to
`textTheme` and `primaryTextTheme`; `SuperTabBarThemeData` is derived automatically.

```bash
flutter pub get
flutter run
```
